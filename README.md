# Roofing Company Website Template

A fully responsive roofing business landing page built with Lovable.

## Features
- Interactive 3-step project estimator
- Dynamic financing calculator
- Draggable before/after image comparison
- ZIP code service area checker
- Customer reviews section
- Mobile responsive design

## Live Demo
https://roofingcompanytemplate.lovable.app

## Built With
- Lovable
- TypeScript
- HTML/CSS
- JavaScript
