# Hawthorne Roofing Portal

Create a premium, ultra-modern mobile-first web application for 'Install It Roofing' based in Hawthorne, CA. 

Design System & Aesthetics:

Do not use a flat or generic layout. Apply a sophisticated dark-mode aesthetic using a deep midnight-charcoal background, crisp off-white typography, and vibrant safety-orange accents for the call-to-action buttons. Give all structural container cards elegant rounded corners, clean border outlines, and a soft backdrop shadow effect so they pop cleanly off the screen.

Key Sections & Layout:

1. Header: A sticky top navigation bar with a high-contrast, pill-shaped button that says 'Call for Emergency Repair'.

2. Hero Section: Display a bold, clean headline: 'Hawthorne's Trusted Roofing Experts'. Right beneath it, add a prominent social proof banner that reads: '⭐⭐⭐⭐⭐ 4.9/5 Stars from 88 Local Google Reviews' in a clean, gold font.

3. Interactive Estimate Tool: Build a beautiful 3-step project estimator wizard. 

   - Step 1 displays sleek, selectable option cards with clean vector icons for 'Asphalt Shingles', 'Flat Roof System', and 'Gutter Installation'. 

   - Step 2 features a smooth, fully operational slider component to select the approximate property square footage (ranging from 500 to 5,000 sq ft). 

   - Step 3 displays a clean contact intake form with an integrated 'Upload Property Photo' drag-and-drop file zone.
